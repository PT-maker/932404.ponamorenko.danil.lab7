## База данных

**departments**

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER, PRIMARY KEY | идентификатор отдела |
| name | TEXT, NOT NULL, UNIQUE | название отдела |

**employees**

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER, PRIMARY KEY | идентификатор сотрудника |
| full_name | TEXT, NOT NULL | ФИО |
| department_id | INTEGER, NOT NULL | внешний ключ на `departments(id)` |
| salary | REAL, NOT NULL | зарплата, `CHECK (salary >= 0)` |

Название отдела хранится только в таблице `departments`. В таблице `employees` лежит лишь `department_id`, а название при необходимости получается через `JOIN`:

```sql
SELECT e.id, e.full_name, d.name, e.salary
FROM employees e
JOIN departments d ON d.id = e.department_id
ORDER BY e.salary DESC;
```

При первом запуске таблицы создаются автоматически и заполняются тестовыми данными (5 отделов, 10 сотрудников). Запросы выполняются с параметрами (`?`), что защищает от SQL-инъекций.

## Маршруты

| Метод | Путь | Описание | Коды ответа |
|-------|------|----------|-------------|
| GET | `/api/employees` | список сотрудников по убыванию зарплаты | 200, 400 |
| GET | `/api/employees?department_id=4` | только сотрудники отдела 4 | 200, 400 |
| GET | `/api/employees/{id}` | один сотрудник | 200, 404 |
| POST | `/api/employees` | создать сотрудника | 201, 400 |
| PUT | `/api/employees/{id}` | обновить сотрудника | 200, 400, 404 |
| DELETE | `/api/employees/{id}` | удалить сотрудника | 204, 404 |
| GET | `/api/departments` | список отделов | 200 |

### Пример создания

```
POST /api/employees
```
```json
{
  "full_name": "Новиков Игорь",
  "department_id": 2,
  "salary": 100000
}
```

Ответ `201`:

```json
{
  "id": 11,
  "full_name": "Новиков Игорь",
  "department_id": 2,
  "salary": 100000.0
}
```

### Ошибки

Все ошибки возвращаются в формате `{"error": "описание"}`:

| Ситуация | Код |
|----------|-----|
| `salary < 0` | 400 |
| пустое `full_name` | 400 |
| несуществующий `department_id` | 400 |
| неверный тип или отсутствующее обязательное поле | 400 |
| сотрудник с таким `id` не найден (GET, PUT, DELETE) | 404 |

Пример ответа при отрицательной зарплате:

```json
{ "error": "salary должна быть числом не меньше 0" }
```
